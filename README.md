# Sign-Up Form

A web-based sign-up form built with HTML and CSS as part of The Odin Project's Foundations curriculum. The project focuses on form design, input styling, page layout, and creating a clean user registration interface.

## Live Demo

[View Sign-Up Form](https://muhammad-aslam-khan.github.io/sign-up-form/)

## Features

- **User Registration Form:** Provides input fields for collecting user information.
- **Custom Form Styling:** Uses CSS to style input fields, labels, buttons, and form elements.
- **Visual Design:** Combines typography, icons, and a background photograph to create an appealing interface.
- **Form Validation:** Uses HTML form attributes to support basic browser validation.
- **Structured Layout:** Organizes the form and accompanying visual elements into a cohesive page design.

## Built With

- HTML5
- CSS3

No CSS frameworks or JavaScript libraries were used.

## Project Purpose

This project was created to practice HTML form elements and CSS layout techniques while building a practical user registration interface.

It provided an opportunity to work with form controls, input validation attributes, positioning, spacing, and visual styling.
